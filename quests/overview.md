# 任务与任务手册

<p class="lead">接取任务后，让目标、计数与导航带你推进。</p>

## 完成一项任务

<div class="steps"><div><b>01</b><strong>对话接取</strong><p>与 NPC 对话，选择当前可接的任务。</p></div><div><b>02</b><strong>查看目标</strong><p>打开任务手册，确认地点、怪物或材料要求。</p></div><div><b>03</b><strong>返回交付</strong><p>达成目标后，按提示向指定人物报告。</p></div></div>

点击<strong>背包 → 主菜单 → 任务手册</strong>打开。手册显示当前可见任务；已完成或尚未开放的任务可能隐藏。

## 看清不同目标

| 目标 | 判断方式 |
| --- | --- |
| 到达地点 | 按当前任务导航前往目标区域 |
| 击败敌人 | 检查目标怪物种类及当前计数 |
| 收集材料 | 检查背包中是否为指定自定义物品 |
| 向 NPC 报告 | 目标完成后继续对话，完成交付 |

## 任务没有推进

先确认任务已接取，再看目标是否要求先完成另一项调查。有的击杀目标只在指定阶段累计；提前收集的物品和提前击杀的怪物不一定按同一种方式计算。

部分地区任务仍在测试，暂不发放奖励，正式奖励待公布。
