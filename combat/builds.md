## 保存自己的方案

点击<strong>背包 → 主菜单 → 职业流派</strong>进入。先完成当前技能树节点加点，再选择「新建 Build」命名保存。每个职业提供 <strong>5 个个人方案位</strong>，切换冷却为 <strong>5 秒</strong>。

| 操作 | 作用 |
| --- | --- |
| 新建 | 保存当前职业的技能树节点等级 |
| 使用 | 切换为所选加点方案 |
| 更新 | 用当前加点覆盖所选方案 |
| 发布 | 将方案分享到公开大厅 |
| 删除 | 删除方案，同时移除公开版本；需要再次确认 |

## 浏览公开方案

Build 大厅展示公开方案的职业、作者、更新时间和评分，可打开方案查看详细加点。预设保存技能树节点等级；装备、普通技能等级与天赋属性单独培养。

## 怎样计算一条路线需要的点数

一条路线的花费包括目标节点和沿途前置节点，共享前置只计算一次。每棵技能树的点数上限为 30 点。

例如「扇形火球」要求「高效火球」5 级。学习满级扇形火球需要投入其自身的 5 点，再加上沿途前置节点的点数。

## 应用后效果为什么不同

| 情况 | 原因 |
| --- | --- |
| 同一方案，伤害比作者低 | 普通技能等级、装备词条、职业等级及目标防御不同；预设不复制这些数值 |
| 预设无法完整使用 | 职业不符、点数不足、未满足节点前置，或方案在技能树更新后失效 |
| 刚切换仍不能立刻攻击 | 切换方案后，仍需等待已开始的攻击间隔结束 |
| 闪现回溯状态还在 | 已开启的回溯持续至结束，再进入冷却 |
| 召唤物没立即变强 | 已有召唤物沿用召唤时的属性，新加点对下一次召唤生效 |
