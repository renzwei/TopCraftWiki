# 武器与穿戴

<p class="lead">防具放入对应护甲栏；戒指、项链、护符和腰带有各自的饰品栏。</p>

## 栏位


| 装备 | 位置 |
| --- | --- |
| 剑、斧、锤、匕首、矛、权杖、魔杖 | 手持武器 |
| 法书、盾牌 | 手持装备；盾牌举盾规则见[盾牌与格挡](combat/defense.md?id=block) |
| 头盔、胸甲、护腿、靴子 | 对应的四个护甲栏 |
| 两枚戒指 | 背包第一排左起第 1、2 格 |
| 项链 | 背包第一排左起第 3 格 |
| 护符 | 背包第一排左起第 4 格 |
| 腰带 / 饰品 | 背包第一排左起第 5 格 |

## 装备要求

装备达到标注的使用等级后可以使用。未鉴定装备需要先用[鉴定卷轴](equipment/identification.md)鉴定；带有职业限制或灵魂绑定的装备还须符合对应条件。

[装备图鉴](equipment/catalog.md)收录各类型的基础属性、成长范围和锻造装备。[套装图鉴](equipment/sets.md)收录四件护甲的组合效果。
