## 实现范围

在现有 Docsify 仓库完成本地改版。统一中性灰白、蓝色强调、紧凑的文档布局；不调整服务器配置与玩法数值。

- `index.html` 提供固定顶栏、搜索 dialog、手机目录遮罩、页内目录容器与返回顶部按钮。
- `assets/modern.css` 是最后加载的全站主题层。统一排版、表格、卡片、提示、表单及导航；章节 CSS 继续维护专有布局。技能树、HUD、背包示意和资源包原图保留游戏内颜色。
- `assets/modern.js` 挂载可折叠章节、面包屑、页内目录、当前章节高亮、前后篇导航、Ctrl/Cmd+K 搜索、宽屏切换和复制功能。宽屏偏好只存入浏览器本地。
- 首页改为九大章节入口和常用资料链接，复用既有 ImageGen 插画及服务器图标。未重新生成插画。

## Docsify 集成注意事项

- 顶栏快捷导航使用带 navigation role 的 div；Docsify 会接管初始 DOM 中的第一个 nav，不能把自定义顶栏直接写成 nav。
- `assets/vendor/search-topcraft.js` 把搜索挂载到 `.wiki-search-host`，旧结构回退到 `.sidebar`；不再选择第一个 aside，避免搜索进入右侧目录后被清除。沿用已有本地全文索引，未引入外部搜索服务。
- `$docsify.topMargin=88` 为固定顶栏预留锚点偏移；CSS 的 scroll-margin 同时覆盖原生定位。不能仅修改 CSS 而忽略 Docsify 自己的滚动。
- 桌面 1440px 及以上、有多个章节的页面显示右侧目录；其他尺寸与宽屏模式使用正文中的可展开目录。技能树全屏继续使用原有独立控件。
- 手机沿用 Docsify 的 body.close 表示抽屉打开。关闭抽屉时使用 inert 避免键盘焦点落入屏幕外目录；遮罩、Escape 和导航点击均可关闭抽屉。
- 原有章节面包屑合并到顶端元信息行，避免重复显示；未更改它们的目标链接。
- 搜索缓存版本为 modern-v20；新增内容后可根据需要递增。
- 章节目录默认展开当前分类，其他分类可按需展开，选择在本次浏览中保留。
- 搜索启动时仅清理 `docsify.search.index/topcraft-wiki-*` 与配对过期时间中的旧版本。索引先于过期时间保存；空间不足、存储禁用、空索引或损坏缓存时使用内存索引并重新加载，不影响其他偏好或存储项。回归用例见 `scripts/check_search.cjs`。
