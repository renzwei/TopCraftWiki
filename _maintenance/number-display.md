# 数值显示规范 · 2026-11-17

## 规则

属性、伤害、成长、概率、经验和计算结果固定显示一位小数，整数属性显示为 `5.0`，大数保留千位分隔。等级、层数、节点点数、物品数量、次数、人数、版本、时钟和科学计数法指数保持原格式。

共用显示层为 `assets/numbers.js`，在 `index.html` 中先于各功能脚本加载。动态装备、技能树、生活职业、秘境结果调用同一格式器。静态属性栏、按表头识别的数值列及带明确计量单位的正文，在 Docsify 挂载后格式化文本节点；不修改链接、输入值、HTML 属性或原始数据。章节标题、菜单、物品链接、代码和公式块不参与格式化。

`data-number-raw` 用于必须精确保留的规则常量：每点耐久维修费率 `0.05` 金币和冷却 `0.05` 秒取整步长。对应生成器已同步标记。其余明确公式位于 `code` 或 `.formula` 等原有公式容器中。静态数值和卖价通过悬停保留原始数值参考。

## 精度与维护

- 格式器只在最终显示时舍入；JSON、输入值、装备强化、掉落概率、秘境成绩与商店 HALF_UP 分币结算不变。
- 技能参数替换和表达式求值使用原始数字，完成求值后才格式化，不能将含千位分隔符或已舍入的显示文本用于后续运算。
- 商店 `salePrice()` 继续返回两位精确结算单价，页面显示为一位，title 展示精确单价。
- 极高层秘境倍率使用一位小数科学计数法，尾数舍入到 10 时进位指数。
- 静态 Markdown 保留原值，后续重新生成页面会自动应用相同显示规则，无需逐篇舍入数据。

## 验证

`scripts/check_numbers.cjs` 覆盖一位小数、千位分隔、百分比成长、整数计数、版本与时钟、相邻链接拆分数值以及参数运算不提前舍入。沿用职业 4,812 组预览、装备 630 组样本、生活职业与秘境边界测试。浏览器核对装备成长表、强化输入、技能树切换、鱼获概率、收购价、秘境倍率和整数层数。
