# 邀请好友与奖励

<p class="lead">分享自己的邀请码，新玩家绑定并达到“玩家”身份后，双方各获 20 金币。累计有效邀请还可获得额外里程碑奖励。</p>

<div class="social-facts"><div><b>1–3 天</b>新玩家填写时的累计登录天数</div><div><b>20 金币</b>每次有效邀请，双方各得</div><div><b>仅一次</b>每位玩家绑定邀请人</div></div>

“玩家”身份需要累计游戏时长达到 **15 分钟**，在线检查有短暂间隔，具体见[社交成长](social/progression.md)。

## 谁可以填写邀请码？

| 条件 | 说明 |
| --- | --- |
| 累计登录天数为 1–3 天 | 包含第 3 天；不是注册后的 72 小时，也不是必须连续登录 3 天。 |
| 尚未绑定邀请人 | 每位玩家只可绑定一次，绑定后不能更换。 |
| 使用他人的有效邀请码 | 不能使用自己的邀请码。 |
| 邀请人仍有可用额度 | 界面显示总额度与剩余额度；没有剩余时不能继续绑定。 |

邀请码为 **4 位字母数字组合**，同时包含字母和数字，输入不区分大小写。绑定无需支付金币，也不需要交易物品。

在确认页核对邀请人的名字后，再点击绑定。

## 怎样判断邀请已经达标？

邀请记录区分**已绑定**、**有效**与**待达标**：

- 已绑定：新玩家已经选择你作为邀请人。
- 有效：被邀请者达到“玩家”身份，计入累计有效邀请。
- 待达标：已经绑定，但还未达到有效邀请条件。

绑定成功不等于已经获得奖励。有效邀请一旦达成，会保留其有效状态；它不是要求双方持续组队或保持好友关系的任务。

已绑定但待达标的邀请也占用额度。自己的邀请码、记录与剩余额度可在邀请界面查看；额度为 0 时，不能继续接受新的绑定。

每个里程碑只奖励一次，各档之间可以累计，也与每人 20 金币的单次奖励叠加。例如累计完成 **5 名有效邀请**，邀请人共获得 **5 × 20 + 120 + 250 = 470 金币**。

奖励自动发放，无需在界面点击领取。领取方当时不在线时，待其上线后发放。

## 常见问题

| 问题 | 原因与操作 |
| --- | --- |
| 提示不是新玩家 | 累计登录天数已超过 3 天，不能再填写邀请码。 |
| 绑定后没有马上拿到金币 | 被邀请者还需达到“玩家”身份；查看记录中的有效／待达标状态。 |
| 邀请人离线了怎么办？ | 达标后的邀请人奖励会等邀请人上线再发放。 |
| 填错邀请码能否换人？ | 成功绑定后不能更改。 |
| 有邀请记录，为什么剩余额度已经减少？ | 待达标的绑定同样占用额度。 |
| 已有好友，是否自动算有效邀请？ | 好友关系与邀请码绑定分别计算，需要完成邀请码绑定和身份达标。 |
