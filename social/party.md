# 组队与招募

<p class="lead">创建自己的队伍，或在组队大厅直接加入公开招募。每队最多 8 人，加入时全队职业等级差不得超过 5 级。</p>

## 创建队伍或寻找队友

<div class="social-steps"><section class="social-step"><header><img class="social-icon" src="assets/server/social/create.png" alt="创建队伍图标"><strong>创建队伍</strong></header><p>点击<strong>背包 → 主菜单 → 组队大厅 → 我的队伍</strong>，再点击“创建队伍”。创建者成为队长。</p></section><section class="social-step"><header><img class="social-icon" src="assets/server/social/recruit.png" alt="公开招募图标"><strong>公开招募</strong></header><p>队长在主城从组队大厅点击“我的队伍”，将“招募”设为启用。队伍会出现在组队大厅，其他玩家可以直接点击加入。</p></section><section class="social-step"><header><img class="social-icon" src="assets/server/social/hall.png" alt="组队大厅图标"><strong>加入已有队伍</strong></header><p>点击<strong>背包 → 主菜单 → 组队大厅</strong>。查看队伍头像中的人数、等级范围和战士／法师／牧师人数，点击加入。</p></section></div>

组队大厅可在主城和落日森林打开。加入公开队伍不需要先创建自己的队伍，也不需要等待队长审批；已有队伍时，需先退出原队伍。

招募默认关闭，只有队长可以开关。队伍满员、队长离开主城或下线、队长变更后，原招募会关闭。队伍重新符合条件后，由队长再次开启招募。

## 单独邀请玩家

在队伍界面点击“邀请玩家”，按提示输入玩家名；也可在脱离战斗后潜行 + 右键对方，打开[玩家档案](social/profile.md)，选择“邀请队伍”。对方在聊天消息中点击**接受**后加入，点击**拒绝**则不加入。

队长和队员都可以邀请。发送者须已有队伍，对方须在线且尚未加入其他队伍。同一队伍再次邀请同一名玩家需间隔 **2 分钟**；邀请和接受时都会检查人数与等级差。

## 等级范围查询

等级限制比较的是**加入后全队的最高等级与最低等级**。例如队伍中有 10、12、15 级玩家，允许加入的等级只有 10–15 级；8 级玩家即使与队长只差 2 级，也会让全队等级差达到 7 级。

<div class="social-calculator" data-party-calculator><label for="party-levels">现有队员等级，用逗号或空格分隔</label><input id="party-levels" type="text" value="10, 12, 15" autocomplete="off" aria-describedby="party-range"><div id="party-range" role="status" aria-live="polite">10、12、15 级的队伍可加入 10–15 级玩家。</div></div>

可加入等级的下限为“当前最高等级 − 5”，上限为“当前最低等级 + 5”，同时受角色等级范围限制。队员升级不会自动被移出队伍；如果升级后等级差超过 5 级，当前队伍暂时不能再加入新队员。

## 为什么点了却没有加入？

| 情况 | 原因与操作 |
| --- | --- |
| 自己已有队伍 | 先退出原队伍，再加入目标队伍。 |
| 目标队伍已满、已离开或关闭招募 | 该招募不能继续加入，重新打开大厅查看其他队伍。 |
| 与队长等级接近，却不能加入 | 对照全队最高与最低等级；队长等级不是唯一条件。 |
| 邀请后升级，接受时失败 | 接受时会重新检查全队等级差和人数。 |
| 在其他世界打不开大厅 | 大厅目前开放于主城和落日森林。 |
| 正在死亡状态 | 复活后再加入公开队伍。 |
