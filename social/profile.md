# 玩家档案与好友

<p class="lead">好友菜单用于查看好友、处理申请和调整社交设置；潜行右键其他玩家打开的档案，则用于查看装备、邀请队伍、交易与赞赏。</p>

<div class="social-note">添加好友、邀请队伍、发起交易和赞赏需要<strong>玩家或以上身份</strong>。新人累计游玩 15 分钟后自动晋升。<a href="#/social/permissions">查看社交身份与权限</a>。</div>

## 打开好友菜单 :id=friends-menu

手持快捷栏中的 **“个人资料”** 物品并右键，打开社交界面；如果打开的是上次浏览的页面，点击菜单底部的 **“打开好友菜单”**。这件物品与背包中的“个人信息”按钮不同，后者用于查看角色战斗属性。

没有“个人资料”物品时，使用 `/friendsgui` 打开好友菜单。

## 添加与接受好友

### 发送申请

手持 **“个人资料”** 物品，潜行并右键目标玩家，可以发送好友申请；如果对方已经向你发来申请，这个操作会接受对方的申请。

对方不在面前或没有入口物品时，使用 `/friend add 玩家名`，将“玩家名”替换为对方的完整游戏名。发送申请后，需要对方接受才会成为好友。

### 接受或拒绝

1. 打开好友菜单，点击底部 **好友申请**。
2. 点击申请人的头像，进入处理页面。
3. 点击绿色的 **接受好友申请**，或红色的 **拒绝好友申请**。

没有待处理申请时，页面会显示“你目前没有待处理的好友申请”。不能收到申请时，可在 **设置 → 是否接收好友申请？** 中选择允许。

## 好友上限

| 身份 | 好友上限 |
| --- | --- |
| 新人 | 暂不能添加好友 |
| 玩家 | 10 人 |
| 活跃玩家 | 30 人 |
| 核心玩家、资深玩家 | 100 人 |

身份条件与完整功能对照见[社交身份与权限](social/permissions.md)。

## 查看与删除好友

| 好友状态 | 列表显示 |
| --- | --- |
| 在线 | 玩家名、在线标记、所在服务器。 |
| 离线 | 玩家名、离线标记、上次在线时间；使用骷髅头像区分。 |

点击菜单底部的排序按钮，可在 **最近在线、名称升序、名称降序、成为好友的时间** 之间切换。好友较多时使用“上一页”“下一页”。

点击好友头像进入详情后，可使用以下操作：

| 操作 | 效果 |
| --- | --- |
| 删除好友 | 解除关系，双方从彼此的好友列表中移除。当前点击后直接执行，没有第二次确认。 |
| 前往好友服务器 | 尝试进入好友所在的服务器；需要对方允许好友前往，且目标服务器可进入。这不是传送到对方身边。 |
| 邀请加入队伍 | 邀请好友加入社交队伍。冒险组队、职业经验分享和秘境准备，请按[组队大厅](social/party.md)的流程操作。 |
| 返回 | 返回好友菜单。 |

## 好友设置 :id=friend-settings

从好友菜单底部进入 **设置**，点击对应选项切换。设置后界面会自动关闭，需要继续调整时重新打开。

| 设置 | 可以选择 |
| --- | --- |
| 是否接收好友申请？ | 允许其他玩家发送申请，或拒绝申请。 |
| 是否接收所有人的组队邀请？ | 允许所有玩家邀请，或只接受好友邀请；作用于好友系统的社交队伍。 |
| 是否接收私信？ | 允许好友发送私信，或不接收私信。 |
| 是否向好友显示在线状态？ | 显示或隐藏自己的在线状态。 |
| 是否接收好友上下线通知？ | 接收或关闭通知。 |
| 是否允许好友前往你的服务器？ | 允许或禁止好友通过好友详情进入你所在的服务器。 |

## 好友数量与身份晋升

晋升活跃玩家需要至少 **5 名好友**。只有双方确认的好友关系才计入人数，待处理申请不计入，也不要求好友同时在线。

此外，还需累计登录 **7 天**、累计游玩 **7 小时**、当前赞赏至少 **3 次**。满足全部条件后，在下次登录时检查晋升。完整条件见[身份晋升与赞赏](social/progression.md)。

## 打开档案与查看资料

脱离战斗后，**潜行右键点击其他玩家**打开装备档案。需要查看档案时，先切换到“个人资料”以外的手持物品，避免触发好友申请操作。NPC 不会打开玩家档案；战斗中也不能使用这一入口。

档案展示对方的头盔、胸甲、护腿、靴子、主手、副手，以及两枚戒指、项链、护符和腰带／饰品。悬停装备可查看物品说明，展示位置不能取走物品。

角色资料沿用个人信息中的展示内容，但**不会公开对方的金币余额**。查看自己的金币请使用自己的个人信息页面。

## 档案中的操作

| 操作 | 用途 |
| --- | --- |
| 邀请队伍 | 邀请对方加入冒险队伍；尚未建队时先打开队伍界面。见[组队与招募](social/party.md)。 |
| 发起交易 | 向对方发送交易请求，接受后打开交换界面。见[金币与玩家交易](social/economy.md)。 |
| 赞赏 | 给帮助过你的玩家点赞；悬停按钮查看冷却或不可用原因。见[赞赏规则](social/progression.md)。 |

好友申请与管理使用上面的 **个人资料物品 → 好友菜单** 流程。

## 常见问题

| 问题 | 原因与操作 |
| --- | --- |
| 打开“个人资料”后不是好友列表 | 它会恢复上次浏览的社交页面，点击底部“打开好友菜单”。 |
| 找不到“个人资料”物品 | 使用 `/friendsgui` 打开好友菜单；发申请可用 `/friend add 玩家名`。 |
| 好友菜单命令提示不可用 | 改用快捷栏“个人资料”物品进入；若物品也缺失，记录完整提示并向工作人员反馈。 |
| 收不到好友申请 | 先确认已达到玩家身份，并在好友设置中允许接收申请。 |
| 好友没有显示在线 | 对方可能离线，或在好友设置中隐藏了在线状态。 |
| 已有 5 名好友，为什么还没晋升？ | 人数只计已接受的好友关系，还需同时满足登录、游玩时长和赞赏条件；晋升在登录时检查。 |
| 点击删除后怎么没有确认页？ | 当前删除操作直接生效；需要恢复关系时，重新发送申请并由对方接受。 |
| 不能前往好友的服务器 | 对方可能关闭了允许前往，或目标服务器限制进入。 |
| 不能向好友发冒险队伍邀请 | 好友关系不免除队伍人数、职业等级差和对方已入队的限制。 |
| 看不到对方金币 | 对方金币余额不在公开档案中展示。 |
