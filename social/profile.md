# 玩家档案与好友

<p class="lead">潜行点击其他玩家，可以查看对方装备和角色资料，发送好友、队伍或交易邀请。</p>

## 打开档案与查看资料

脱离战斗后，**潜行右键点击其他玩家**打开档案。NPC 不会打开玩家档案；战斗中也不能使用这一入口。

档案展示对方的头盔、胸甲、护腿、靴子、主手、副手，以及两枚戒指、项链、护符和腰带／饰品。将鼠标移到装备上可查看物品说明；这些展示位置不能取走对方物品。

角色资料沿用个人信息中的展示内容，但**不会公开对方的金币余额**。查看自己的金币请使用自己的个人信息页面。

## 添加与接受好友

1. 打开对方档案，点击**添加好友**。
2. 对方收到好友请求，在聊天消息中点击**接受**或**拒绝**。
3. 接受后，双方可在好友列表中查看彼此。

使用 `/mmocore:friends` 打开好友列表。列表底部的“新的好友请求”按钮也可用于发起请求，按提示输入玩家名。输入过程可按提示取消。

好友请求需要对方在线；不能添加自己。请求处于冷却期间时，等待提示中的剩余时间后再发送。

## 查看与删除好友

| 好友状态 | 列表显示 |
| --- | --- |
| 在线 | 玩家名、职业等级、职业、在线时间 |
| 离线 | 玩家名、距上次在线的时间 |

**右键好友头像**进入移除确认，确认后解除好友关系；取消则保留。好友关系不会自动创建队伍，也不会自动接受交易邀请。

## 好友数量与身份晋升

<div class="social-note">档案好友列表与身份晋升所需的好友人数目前尚未同步。通过档案添加好友后，身份晋升的好友条件暂时不会因此增加。</div>

好友列表仍可正常用于查看和管理好友关系。[社交成长](social/progression.md)页分别列出身份条件与当前状态。

## 常见问题

| 问题 | 原因与操作 |
| --- | --- |
| 潜行点击没有打开档案 | 先脱离战斗，并确认点击的是玩家。 |
| 刚才还在，发送邀请时提示不在线 | 对方已离线或当前对你不可见，重新打开档案后再操作。 |
| 不能向好友发队伍邀请 | 好友关系不免除队伍人数、等级差和对方已入队的限制。 |
| 队伍邀请要求先建队 | 先完成创建，再从对方档案发送邀请。 |
| 无法删除好友 | 右键头像后还需完成移除确认。 |
| 看不到对方金币 | 对方的金币余额不在公开档案中展示。 |
