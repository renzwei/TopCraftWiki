# 樱落溪涧

<p class="lead">白樱与墨樱幻影庇护着洞中的生死将军。沿途收集咒玉、救援幸存者，击败双幻影解除仪式，再在将军的死相中引导魂魄归位。</p>

## 咒玉与双幻影

沿途怪物会提供白樱咒玉、墨樱咒玉。<strong>拾取后立即为全队生效</strong>，不需要打开背包右键使用，也不需要每名队员分别收集。

<div class="dg-mechanics"><div><h3><img class="dg-icon" src="assets/server/dungeons/white-jade.png" alt="">白樱咒玉</h3><p>提高白樱幻影受到的伤害。对白樱幻影生效，不提高墨樱幻影或将军受到的伤害。</p></div><div><h3><img class="dg-icon" src="assets/server/dungeons/black-jade.png" alt="">墨樱咒玉</h3><p>提高墨樱幻影受到的伤害。对墨樱幻影生效，不提高白樱幻影或将军受到的伤害。</p></div></div>

每种咒玉的伤害收益在 <strong>30 枚</strong>达到上限。对应幻影的受伤倍率为 <strong>10<sup>咒玉数量÷30</sup></strong>；每增加一枚，倍率约再乘 <strong>1.0798</strong>。

| 全队收集的对应咒玉 | 幻影受到的伤害 |
| --- | --- |
| 0 枚 | 1 倍 |
| 10 枚 | 约 2.15 倍 |
| 20 枚 | 约 4.64 倍 |
| 30 枚及以上 | 10 倍 |

幻影难以击败时，可以继续清理沿途敌人，补足对应颜色的咒玉；无需强行在低倍率下消耗时间。

## 救援幸存者

救援是第一幕的可选目标。靠近幸存者，清理附近守卫后右键，持续 <strong>4 秒</strong>完成救援。救援期间保持在 <strong>3 格</strong>以内；受到伤害、离开范围或施法被打断时，需要重新尝试。

每救出一人，全队获得一层<strong>同心</strong>：伤害加成、持续伤害加成、召唤物伤害加成各提高 <strong>5%</strong>。最多救援 <strong>4 人</strong>，对应各 <strong>20%</strong>。同心在本次秘境中持续提供收益；进入将军阶段后，不能再开始新的救援。

| 幸存者 | 位置 X / Y / Z | 到达后要做什么 |
| --- | --- | --- |
| 第一处 | 550.5 / 2 / 95.5 | 清理附近守卫后救援 |
| 第二处 | 528.5 / 4 / 165.5 | 清理附近守卫后救援 |
| 渡船对岸 | 666.5 / 1 / 117.5 | 乘船到达后靠近救援 |
| 第四处 | 515.5 / 1 / 251.5 | 清理附近守卫后救援 |

队伍可以由一人进行救援，其他成员负责阻挡或清理敌人，避免救援读条受到伤害中断。

## 渡船与落水

渡船连接两岸：出发交互点位于 <strong>648.5 / 0 / 129.5</strong>，抵达 <strong>666.5 / 1 / 117.5</strong>附近。对岸返程交互点位于 <strong>666.5 / 1 / 119.5</strong>，右键可回到出发岸。

<strong>溪水不可游渡。</strong> 落水会受到眩晕，约 <strong>0.5 秒</strong>后死亡，并产生普通死亡罚时。过河应走可通行地面或使用渡船。

## 击败双幻影

白樱幻影位于 <strong>617.5 / 2 / 188.5</strong>，墨樱幻影位于 <strong>627.5 / 2 / 188.5</strong>。两只都击败后，生死将军的仪式庇护解除，将军在洞穴中央苏醒。

先击败其中一只不会直接结束第一幕。可以按队伍已收集的咒玉数量决定攻击顺序；想完成救援，应在第二只幻影倒下前处理完毕。

## 生死将军

将军按固定时间在<strong>生相 40 秒 → 死相 24 秒</strong>之间循环，不以生命百分比切换。每轮死相都需要重新完成两次引魂。

<div class="dg-timeline"><div style="flex:40"><strong>生相 · 40 秒</strong><small>正常承伤；躲避或反制断生斩</small></div><div style="flex:24"><strong>死相 · 24 秒</strong><small>受到伤害降至 20%；引魂两次恢复正常承伤</small></div></div>

### 生相：断生斩

生相中将军正常承受伤害。每轮开始至少 <strong>12 秒</strong>后施放断生斩：蓄力 <strong>2 秒</strong>，覆盖半径 <strong>3.5 格</strong>，造成自身攻击力 <strong>120%</strong>的伤害。该招式可以反制；也可以在预警结束前离开圆圈。

### 死相：连续两次引魂

进入死相后，将军返回中央 <strong>622.5 / 2 / 192.5</strong>，暂时只承受正常伤害的 <strong>20%</strong>。场中出现归魂印与追魂；追魂选定附近玩家并持续追随。

1. 先找到西侧归魂印，位于 <strong>616.5 / 2 / 192.5</strong>。被追魂追踪的玩家绕到印记另一侧，让魂魄经过印记。
2. 魂魄距离归魂印 <strong>1.5 格</strong>以内时归位。约 1 秒后，出现第二轮追魂与东侧归魂印，位于 <strong>628.5 / 2 / 192.5</strong>。
3. 再引导一次，完成两次归魂。将军立刻恢复正常承伤，本轮不再发射新的魂弹；剩余死相时间可以用来输出。

## 常见问题

### 咒玉不在背包里，是没有捡到吗？

咒玉拾取后立即生效。查看本局咒玉计数与对应幻影的受伤倍率即可，不需要再使用物品。

### 将军死相中为什么几乎打不动？

死相初始只承受 20% 伤害。先引导两只追魂依次进入归魂印，完成破甲后再集中输出。

### 单人能完成引魂吗？

可以。西侧与东侧印记按顺序出现，分别引导即可；印记需要的是追魂进入，不是玩家站在上面。

### 救援一直中断怎么办？

清理守卫，避免受到伤害，并在 4 秒读条期间保持距离不超过 3 格。将军阶段开始后，救援不再开放。
