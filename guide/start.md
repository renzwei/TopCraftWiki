# 第一次冒险

<p class="lead">从选择职业、绑定第一个技能开始，认识背包、主城服务和任务入口。</p>

<figure><img class="chapter-art" src="assets/art/adventure.webp" alt="夕阳下的方块营地、森林小径与远方遗迹" loading="lazy"><figcaption>冒险主题插画；主城设施位置见“主城与服务”。</figcaption></figure>

尚未连接服务器时，先阅读[加入游戏与资源包](guide/join.md)。进入后按 **E** 打开背包；如果修改过按键，请使用“打开／关闭物品栏”对应的按键。

## 先了解新人身份

首次加入时为**新人**：聊天每 10 秒可发 1 条，暂不能组队、添加好友、赞赏或与玩家交易。累计游玩达到 **15 分钟**后自动晋升**玩家**，身份每 **2 分钟**检查一次。

这段时间可以先选择职业、装配技能、认识主城服务。晋升后，好友上限为 **10 人**，邀请总额度为 **3 次**；更高身份继续提高额度。完整规则见[社交身份与权限](social/permissions.md)。

## 选择职业

按 <strong>E</strong> 打开背包，点击右上方的<strong>职业选择</strong>图标。三种职业都有自己的等级、技能和加点路线。

| 职业 | 战斗方式 | 1 级技能 |
| --- | --- | --- |
| [战士](combat/warrior.md) | 近身作战，以挥斩、突进和范围攻击压制敌人 | 横扫 |
| [法师](combat/mage.md) | 远程释放火焰、冰霜与雷电法术，以闪现调整位置 | 火球术 |
| [牧师](combat/priest.md) | 使用神辉剑气攻击，并以治疗和增益支援友军 | 神辉斩 |

<div class="guide-steps"><section class="guide-step"><strong>查看职业介绍</strong><p>悬停战士、法师或牧师图标，阅读战斗定位。点击下方的“选择战士”“选择法师”或“选择牧师”按钮。</p></section><section class="guide-step"><strong>确认选择</strong><p>确认页显示目标职业与成长记录。点击“确认选择”完成选择；想重新考虑时，点击“返回职业列表”。</p></section><section class="guide-step"><strong>打开技能</strong><p>选择完成后，回到背包点击“打开技能”，开始装配第一个技能。</p></section></div>

<div class="guide-note">职业选择和切换将取消职业点消耗。调整上线前，若仍遇到“职业点不足”提示，可向工作人员反馈。</div>

职业上限为 **30 级**，六个技能分别在 **1、4、8、12、18、24 级**解锁，同时可装配五个。各职业的技能与成长见[职业选择](combat/classes.md)。

## 绑定第一个技能

以法师的**火球术**为例；战士选择横扫，牧师选择神辉斩，操作相同。

1. 打开背包，点击<strong>打开技能</strong>，在左侧技能列表中点击<strong>火球术</strong>。
2. 将鼠标移到界面下方的**技能槽 1**，说明中的“当前选中”会显示所选技能。
3. **左键点击技能槽 1**完成绑定；该槽位显示火球术图标。
4. 关闭界面，朝向目标按**鼠标左键**施放。其他槽位的操作见[基本操作与按键](guide/controls.md)。

想换技能时，重新选择另一项已解锁技能，再左键点击目标槽位。**右键点击槽位**可解绑；解绑不等于重置技能等级或技能树加点。

技能未达到解锁等级时，先提升职业等级。图标上出现倒计时则需等待冷却；法力不足时需先恢复法力。图标含义见[技能栏的四种状态](guide/interface.md?id=技能栏的四种状态)。

## 穿戴与使用物品

按 E 打开背包，将头盔、胸甲、护腿、靴子放入左侧对应位置，武器放在主手快捷栏。戒指、项链、护符、腰带／饰品使用背包第一排左侧的专用栏位。

- **先读物品说明。** 装备可能要求职业、等级或鉴定；不满足条件时无法正常使用。
- **额外背包用于储物。** 将装备放入额外背包不会穿戴它。
- **食物与药水按物品说明使用。** 手持后右键使用常见食物与药水，恢复与增益效果、冷却时间见[食物与药水](equipment/consumables.md)。

具体装备位置与限制见[武器与穿戴](equipment/slots.md)，未鉴定装备的处理见[鉴定与修理](equipment/identification.md)。

## 任务与下一步探索

与任务 NPC 对话接取任务后，从**主菜单 → 任务手册**查看目标、数量和进度。达到目标后，按任务提示返回指定人物报告。打开任务手册本身不会自动接取全部任务。

主城与落日森林之间的 **NPC 传送入口尚未开放**。地区、怪物与任务资料可先从[世界地图与旅行](world/overview.md)查询；入口开放后再按 NPC 指引出发。

## 与原版生存的区别

| 内容 | TopCraft 中的用法 |
| --- | --- |
| 采集与建造 | 默认冒险模式；生活采集使用对应工具与资源点，不按普通生存的自由挖掘流程进行。 |
| 个人合成栏 | 替换为背包功能入口，物品制作使用相应工匠与制作站。 |
| 饥饿 | 饥饿值不会正常消耗，原版高饱和度快速回血关闭。 |
| 恢复 | 依靠生命恢复、治疗技能、食物或药水；具体效果见物品与技能说明。 |
| 等级 | 职业等级与八项生活职业分别成长。 |
