## 常用操作的点击路径

| 想做什么 | 游戏内怎么进入 |
| --- | --- |
| 查看战斗属性 | 背包 → 个人信息；点击后打开角色详情。 |
| 分配天赋点 | 背包 → 打开技能 → 左下角“天赋属性”。 |
| 给技能树加点 | 背包 → 打开技能 → 右下角“技能树” → 选择对应技能树。 |
| 查看生活职业等级 | 背包 → 主菜单 → 生活技能。 |
| 接取每周生活委托 | 背包 → 主菜单 → 生活委托 → 点击“每周任务”。 |
| 创建或管理队伍 | 背包 → 主菜单 → 组队大厅 → 我的队伍。 |
| 添加与管理好友 | 手持快捷栏“个人资料”物品右键 → 打开好友菜单；手持此物品潜行右键对方可发申请。见[好友菜单](social/profile.md)。 |
| 赞赏或交易 | 脱离战斗后，潜行 + 右键对方 → 在玩家档案中点击对应按钮；手持物品不要选择“个人资料”。 |
| 领取每日、每周或每月礼包 | 前往主城，右键“奖励” NPC → 选择对应礼包。 |

组队大厅可在主城与落日森林打开。NPC 位置见[主城服务地图](world/town.md)，完整步骤见对应玩法页面。需要查找备用命令时，可使用[帮助中的命令速查](guide/commands.md)。

## 队伍面板与状态图标

组队后，侧边的队伍面板展示队员资料以及生命、法力、护盾状态，队长带有专门标记。队伍人数较多时会使用紧凑布局；面板中的角色状态不代表该队友一定处于经验分享范围内，分享距离见[组队协作与收益](social/cooperation.md)。

战斗中的增益与减益使用状态图标提示。图标对应的效果、持续时间或层数按具体技能计算；常见状态可在[状态与控制](combat/status-effects.md)中查询。

## 任务侧栏与导航

任务侧栏显示当前追踪目标与进度。导航提示目标方向及高低差；跟随方向移动时，也要注意目标所在的平台、洞穴或高地。

进入秘境等场景后，任务侧栏可能暂时隐藏。可从主菜单打开任务手册继续查看任务；是否已完成报告，以任务手册与 NPC 对话为准。生活委托拥有独立的每日、每周目标，见[生活委托](life/commissions.md)。
