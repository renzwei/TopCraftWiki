# 加入游戏与资源包

<p class="lead">使用 Minecraft Java 版 1.21，连接 topcraft.cc。首次进入时，等待服务器资源包加载完成，再打开背包选择职业。</p>

<div class="guide-facts"><div><b>topcraft.cc</b>服务器地址</div><div><b>Java 版 1.21</b>客户端版本</div><div><b>启用</b>服务器资源包</div></div>

## 添加服务器

<div class="guide-steps"><section class="guide-step"><strong>启动游戏</strong><p>在启动器中选择 Minecraft Java 版 <b>1.21</b>，进入游戏主菜单，点击“多人游戏”。</p></section><section class="guide-step"><strong>填写连接信息</strong><p>点击“添加服务器”，名称填写 TopCraft，服务器地址填写 <code>topcraft.cc</code>。</p></section><section class="guide-step"><strong>允许资源包</strong><p>将“服务器资源包”设为“启用”，保存后加入。如果弹出下载确认，接受服务器资源包。</p></section><section class="guide-step"><strong>等待加载完成</strong><p>首次下载和加载可能需要一些时间。进入后按 <b>E</b> 打开背包，查看自定义界面与按钮是否正常显示。</p></section></div>

资源包会在进入世界前的加载阶段发送。拒绝资源包或加载失败时，连接可能中断；重新连接前，先查看屏幕上的失败提示。

## 怎样知道资源包已经生效？

背包会显示棕色的角色区域，技能、职业选择和主菜单使用专门的图标。技能栏、物品模型及菜单背景也会随资源包加载。

<div class="guide-demo"><div class="guide-menu"><div class="guide-static-icon"><img src="assets/server/guide/inventory-backpack.png" alt="额外背包图标">额外背包</div><div class="guide-static-icon"><img src="assets/server/guide/inventory-skills.png" alt="技能图标">打开技能</div><div class="guide-static-icon"><img src="assets/server/guide/inventory-class_select.png" alt="职业选择图标">职业选择</div><div class="guide-static-icon"><img src="assets/server/guide/inventory-main_menu.png" alt="主菜单图标">主菜单</div></div><p class="guide-caption">背包中使用的四个功能图标。完整位置见“菜单与战斗界面”。</p></div>

图标显示为方框、物品变成普通纸张或菜单背景缺失时，先按下方对应情况处理。技能槽没有技能图标，也可能只是尚未绑定技能，见[第一次绑定技能](guide/start.md?id=绑定第一个技能)。

## 无法连接或资源包显示异常

连接失败时，先核对服务器地址与客户端版本，并保留完整提示。图标变成方框或背景缺失时，重新确认“服务器资源包”已启用。

按具体情况继续查看[连接与显示问题](guide/troubleshooting.md)。只有某个技能槽为空时，也可能是尚未绑定技能，见[技能栏状态](guide/interface.md?id=技能栏的四种状态)。

进入游戏后，点击<strong>背包 → 主菜单 → 服务器公告</strong>查看公告与通知。公开反馈入口尚未确定，可先按[问题反馈模板](guide/feedback.md)保存记录。
