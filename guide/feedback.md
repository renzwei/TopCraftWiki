# 问题反馈

<p class="lead">把发生时间、操作步骤和实际结果记下来，附上完整提示或截图，方便复现你遇到的问题。</p>

<div class="help-notice"><strong>反馈入口待公布。</strong> 目前尚未确定公开的反馈渠道。下方模板可以复制后填写并保存；此页面不会提交报告。</div>

## 先查找已有答案

- 连接失败、资源包或图标异常：[连接与显示问题](guide/troubleshooting.md)。
- 技能、装备、任务、组队或秘境中的疑问：[帮助与常见问题](guide/help.md)。
- 找不到功能入口：[菜单与战斗界面](guide/interface.md)；需要命令时可查阅[常用命令](guide/commands.md)。

## 截图与记录要包含什么？

| 问题 | 建议保留的内容 |
| --- | --- |
| 无法连接 | 完整断开提示、发生时间、客户端版本，以及下载或加载资源包到了哪一步。 |
| 界面或外观异常 | 整个界面、物品完整名称；同一物品在背包与手持时的对照。 |
| 技能没有触发或效果异常 | 技能名称、等级、所绑定槽位，以及施放时的技能栏、法力与状态。 |
| 道具、修复、强化或交易异常 | 操作前后物品提示与数量、耐久或强化等级，相关时间和交易对象。 |
| 任务或礼包无法领取 | 任务名称、当前目标、进度、剩余倒计时与领取时的完整提示。 |
| 秘境成绩或钥匙异常 | 地图、层数、队员、钥匙使用前后情况、结算画面及有无断线或离开。 |
| Wiki 文字或数值有误 | 页面链接、对应段落、游戏内实际说明或截图。 |

截图应保留与问题相关的界面，遮去无关的私人聊天和个人信息。反馈不需要账号密码、验证码或登录凭据。

## 怎样写清楚操作步骤？

例如技能没有释放，可以写：“打开技能界面，将飞锤绑定到第 2 槽 → 关闭界面 → 按交换副手键。技能栏没有冷却倒计时，法力为……，屏幕出现……提示。”

尽量写出实际按了什么、当时看到了什么。如果再次操作能够正常使用，也请记录两次操作之间的差异。
