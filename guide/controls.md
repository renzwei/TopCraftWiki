# 基本操作与按键

<p class="lead">技能使用鼠标、潜行、交换副手和丢弃键的组合。记住动作名称，修改按键后也能找到对应操作。</p>

## 常用操作

| 操作 | 默认按键或方法 | 说明 |
| --- | --- | --- |
| 移动与跳跃 | W / A / S / D、空格 | 使用 Minecraft 的移动设置。 |
| 打开背包 | E | 查看装备、储物与五个功能入口。 |
| 关闭界面 | Esc | 退出当前菜单。 |
| 与服务 NPC 交互 | 右键 | 打开对话、商店或对应服务。 |
| 查看其他玩家档案 | 潜行 + 右键玩家 | 脱离战斗后使用，可查看装备并发送队伍或交易请求；手持“个人资料”物品时，同一操作用于好友申请。 |
| 使用食物、药水 | 手持物品后右键 | 具体效果、限制与冷却按物品说明。 |
| 查找常用功能 | 背包中的主菜单图标 | 打开任务手册、生活委托、生活技能、组队大厅、职业流派和服务器公告。 |
| 队伍聊天 | 消息前加 @ | 例如 <code>@在营地集合</code>。 |

这些是**已绑定技能**的施放操作。先在技能界面选中技能，再左键点击下方对应槽位；完整步骤见[绑定第一个技能](guide/start.md?id=绑定第一个技能)。

潜行组合技能先按潜行，再紧接着点击鼠标。按键组合的接续窗口为 **0.5 秒**；若已经潜行很久，再点击没有触发预期技能，可松开潜行后重新连续操作。

更改“交换副手物品”的按键后，技能槽 2 使用新按键；更改“丢弃所选物品”的按键后，技能槽 5 使用新按键。HUD 上的默认键位图标可作为槽位提示，实际操作以自己的控制设置为准。

## 技能界面的鼠标操作

| 所在位置 | 操作 | 结果 |
| --- | --- | --- |
| 技能列表 | 点击已解锁技能 | 选中这项技能。 |
| 下方技能槽 | 左键 | 将选中的技能绑定到此槽位。 |
| 下方技能槽 | 右键 | 解绑此槽位。 |
| 已绑定的技能槽 | Shift + 左键 | 选中此槽位已经绑定的技能。 |

更换槽位不会重置技能等级与技能树加点。需要重置或保存方案时，阅读[升级与技能加点](combat/progression.md)及[加点方案与预设](combat/builds.md)。

## 按键没有触发时

| 看到的情况 | 操作 |
| --- | --- |
| 技能槽为空 | 点击<strong>背包 → 打开技能</strong>，选中技能后左键点击槽位。 |
| 图标显示倒计时 | 等待倒计时或攻击间隔结束。 |
| 图标显示法力警示 | 等待法力恢复，或使用能恢复法力的物品、技能。 |
| 被眩晕、冻结或沉默 | 等待对应控制结束，详见[状态与控制](combat/status-effects.md)。 |
| 换过按键后原键失效 | 在控制设置中查看交换副手、丢弃或潜行对应的新按键。 |
